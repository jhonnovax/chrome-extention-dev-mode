Dev Mode Settings

Rules are applied per mode on the domains where a mode is active. Changes take effect on save without reloading the extension.

Checking local server…

Map Local

Redirects matching requests to a local folder. Use * as wildcard; the last wildcard becomes the path under the folder. Folders are sent to the local server automatically when you save.

While Development or Preview is active, Chrome shows a "Dev Mode started debugging this browser" bar on those tabs — that is the interception at work (the page keeps its real URL, like Charles). Clicking Cancel on the bar pauses mapping for that tab until the next navigation.

Rewrites

Regex matched against the full URL; the matched part is replaced using $1…$n. The page never sees the new URL. Rewrites run before Map Local, so a rewritten URL can then be mapped locally.
